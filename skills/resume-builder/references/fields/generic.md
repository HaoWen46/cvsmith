# Field guide: unlisted fields

Research the target instead of importing technology-resume assumptions.

1. Name the field, role family, level, market, and actual gatekeeper precisely.
2. Use the posting plus a small set of current examples from credible local career services, professional bodies, or successful practitioners.
3. Extract the expected section order, page range, credentials, portfolio or license needs, useful outcomes, vocabulary, and presentation register.
4. Confirm any material uncertainty with the user.
5. Apply the shared evidence, practical-exposure, and writing rules using that field's outcomes and reader.

Do not claim a convention from memory when it would materially change the document and can be checked cheaply.

The schema supports conventional education, experience, projects, skills, publications, and awards; if the target requires a license-first section, a government form, a portfolio, an exhaustive CV, or another structurally different artifact, name the limitation and use the required format rather than mislabeling a nearby field.
